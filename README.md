# Momora

> A responsive plant and gardening website built using HTML and Tailwind CSS.

## About

→ **Momora** is a modern plant and gardening website featuring plants, seeds, soil, compost, and fertilizers.

→ Designed with a clean nature-inspired interface and responsive layout.

## Features

→ Responsive navigation

→ Hero section

→ About section

→ Best Sellers

→ Product categories

→ Products page with search interface

→ Customer reviews

→ Contact form

→ Responsive footer

## Technologies

→ HTML5

→ Tailwind CSS

→ Font Awesome

## Pages

→ **Home** — Hero, About, Best Sellers, Categories, Reviews, and Newsletter

→ **Products** — Plant, seed, soil, compost, and fertilizer products

→ **Contact** — Contact form and contact information

## Responsive Design

→ Fully responsive layout for mobile, tablet, and desktop screens.
